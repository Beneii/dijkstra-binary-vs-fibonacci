# Binary implementation

Primary author responsible for this module: James Novosel.
AI assistance is disclosed in James's report section.

`binary_heap.hpp` implements the indexed binary min-heap. `dijkstra_binary.cpp` and its header contain James's Dijkstra implementation. The original heap test is at `tests/binary_heap_test.cpp` in the repository root. Graph types and the original CSV loader are in `graph.hpp` and `graph.cpp`; the matched harness uses the shared strict parser and converts the graph before timing.

These source files match the source hashes of the recorded 4 November experiment.
